API is running

Multi-user health and life tracker — gym, nutrition, habits and media. Express API with session-based authentication over Postgres.

No web interface yet — this deployment is the API only

Endpoints

  • GET/api/health
  • POST/api/auth/register
  • POST/api/auth/login
  • POST/api/auth/logout
  • GET/api/auth/me
  • POST/api/auth/change-password
  • POST/api/auth/forgot-password
  • POST/api/auth/reset-password
  • GET/api/profile
  • PATCH/api/profile
  • DEL/api/profile

Authenticated routes require a session cookie, so they are not browsable here — send credentials with credentials: 'include' or curl's -b/-c. Try /api/health for a response without one.
